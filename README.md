# Steel & Fire — Campaign App

## Files in this repo

```
.github/workflows/build.yml   — Auto-build workflow (don't touch)
build.js                       — Build script (don't touch)
src/App.jsx                    — Source code (update this for new features)
src/styles.css                 — Styles (don't touch)
assets/world_map.jpg           — World map image (replace to update map)
assets/barony_map.jpg          — Oghill Barony map (replace to update map)
assets/icons/                  — Settlement icons (replace to update icons)
```

## How to update

### New feature from Harvey:
1. Get updated App.jsx from Harvey
2. Go to your GitHub repo
3. Click `src/App.jsx` → Edit (pencil icon) → paste new content → Commit
4. GitHub automatically builds and deploys in ~60 seconds
5. Hard refresh the app (Ctrl+Shift+R)

### Replace a map image:
1. Go to GitHub repo → `assets/` folder
2. Click the file → Upload → replace with new file → same filename
3. GitHub rebuilds automatically
